# BookReviews

A book presentation app built with Angular 19, developed as a personal project to practice Angular after completing OpenClassrooms Angular courses.

The app displays a list of books and allows users to navigate to individual book detail pages.

## Tech stack

- Angular 19
- TypeScript
- SCSS

## Local setup

Install dependencies and start the development server:

```bash
npm install
ng serve
```

Open your browser at `http://localhost:4200`
